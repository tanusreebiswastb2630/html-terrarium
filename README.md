
# My Terrarium 🌱

A small digital garden built with HTML and CSS.

My Terrarium is a beginner-friendly front-end project focused on layout, styling, responsive design, and accessibility. It presents five plants inside a glass-inspired container with a layered soil bed and a calm botanical color palette.

## Features

- Responsive terrarium layout
- Five individually labelled plant illustrations using emoji
- Glass-inspired container with reflections and shadows
- Layered soil with decorative details
- Responsive typography and spacing
- Accessible labels and semantic HTML
- Reduced-motion support

## Built With

- HTML5
- CSS3
- Flexbox
- CSS custom properties
- Media queries

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Resize the browser window to test the responsive layout.

No build tools or package installation are required.
